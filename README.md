### 🚀 Proyectos Destacados

#### 🚇 Asset Manager — Sistema de Gestión de Activos (EMOVA)

Sistema de gestión de activos e infraestructura desarrollado para **EMOVA MOVILIDAD S.A.** Permite administrar de forma jerárquica el inventario de activos de la empresa (relaciones padre/hijo, navegación en árbol), controlar su ciclo de vida mediante estados personalizables, y programar y ejecutar tareas de mantenimiento con niveles de criticidad, calendario, drag & drop y programación masiva.

Incluye **RBAC** con permisos granulares por área, auditoría completa de operaciones, papelera de reciclaje con soft delete, y vista analítica expuesta para **Power BI**.

> React · Node.js/Express · PostgreSQL · Docker Compose · Nginx

#### 📊 Pipeline de Datos Operativos (Emova)

ETL de gran escala para digitalización de datos de mantenimiento y operación: parsing de imágenes, limpieza y estructuración para análisis en Power BI.

#### 🤖 Local AI Lab & Home Server

Infraestructura on-premise para inferencia local (Ollama, ComfyUI) y domótica (Home Assistant + n8n), corriendo en hardware propio (RTX 5070 Ti, mini PCs).
