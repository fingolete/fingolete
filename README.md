### 🚀 Proyectos Destacados

#### 🚇 Sistema de Asset Management (Subte de Buenos Aires)
Plataforma propia (Next.js, PostgreSQL + PostGIS, Prisma) para gestión de activos ferroviarios bajo lineamientos ISO 55000, con jerarquía de 4 niveles y modelado de activos lineales (vías) mediante índice de condición TCI.

#### 🛸 Inspección con Drones en Infraestructura Crítica
Desarrollo de capacidad de inspección con drones FPV (BETAFPV Pavo20 Pro II + DJI O4) para túneles, estaciones y material rodante del Subte. En proceso de certificación **RAAC 102** (ANAC) con DronesVIP, con la mira puesta en aplicaciones más allá del caso de uso ferroviario.

#### 📊 Pipeline de Datos Operativos (Emova)
ETL de gran escala para digitalización de datos de mantenimiento y operación: parsing de imágenes, limpieza y estructuración para análisis en Power BI.

#### 🤖 Local AI Lab & Home Server
Infraestructura on-premise para inferencia local (Ollama, ComfyUI) y domótica (Home Assistant + n8n), corriendo en hardware propio (RTX 5070 Ti, mini PCs).
